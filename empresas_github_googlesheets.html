Configuración inicial — 3 pasos

Solo hay que hacerlo una vez. Tarda menos de 10 minutos.

Paso 1 — Google Sheets

Crear la hoja de datos

Ve a sheets.google.com y crea una nueva hoja. Llámala como quieras (ej: "Empresas Internacionales"). Copia la ID que aparece en la URL — es la parte entre /d/ y /edit.

Ejemplo de URL: https://docs.google.com/spreadsheets/d/1BxiMV...TUKUntU/edit

Después de crear el Sheet, ve a Archivo → Compartir → Cualquier persona con el enlace puede editar (para que todos los usuarios puedan guardar datos).

Paso 2 — Google Apps Script (el puente)

Crear el script que recibe los datos

En tu Google Sheet ve a Extensiones → Apps Script. Borra lo que haya y pega este código:

function doGet(e){return handleRequest(e);} function doPost(e){return handleRequest(e);} function handleRequest(e){ var ss=SpreadsheetApp.getActiveSpreadsheet(); var sheet=ss.getSheetByName('Datos')||ss.insertSheet('Datos'); var action=e.parameter.action||'read'; var out=ContentService.createTextOutput(); out.setMimeType(ContentService.MimeType.JSON); if(action==='read'){ var data=sheet.getDataRange().getValues(); out.setContent(JSON.stringify({ok:true,data:data})); } else if(action==='write'){ var rows=JSON.parse(e.parameter.rows||'[]'); sheet.clearContents(); if(rows.length>0)sheet.getRange(1,1,rows.length,rows[0].length).setValues(rows); out.setContent(JSON.stringify({ok:true})); } return out; }

Pulsa Guardar (icono del disco) → luego Implementar → Nueva implementación → Tipo: Aplicación web → Ejecutar como: Yo → Acceso: Cualquier persona → Implementar.

Copia la URL de la aplicación web que aparece al final:

Si Google te pide autorizar permisos, acéptalos — es para que el script pueda escribir en tu Sheet.

Paso 3 — Listo

Guardar configuración

Pulsa el botón de abajo. La configuración se guarda en tu navegador y el dashboard quedará conectado a tu Google Sheet. Cualquier persona que abra el dashboard desde GitHub Pages y complete estos mismos pasos 1 y 2 (con el mismo Sheet) verá los mismos datos.

La URL del script también se puede compartir directamente entre usuarios del equipo para que todos apunten al mismo Sheet sin repetir la configuración.
